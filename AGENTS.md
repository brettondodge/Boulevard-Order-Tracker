# AGENTS.md

## Project workflow

- Before substantial changes, ensure the current work has a Git checkpoint.
- After completing a feature or fix, run appropriate checks, commit the task’s changes with a descriptive message, and push the working branch to GitHub.
- Keep unfinished work separate from the main branch.
- Never commit passwords, API keys, .env files, database files, or customer-data backups.
- At the end of each task, report the branch, commit, GitHub commit link, checks performed, and whether the push succeeded. Clearly state if anything remains saved only locally.

## Safety rules

- Do not publish the app or provision hosting as part of a task unless explicitly asked to do so.
- Keep local configuration secrets out of the repository and do not store them in tracked files.
- Preserve existing project work and avoid force-pushing branch history.
